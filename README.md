# LombongoCare

## Descrição do Projeto

O **LombongoCare** é uma plataforma de gestão de finanças pessoais desenvolvida para ajudar utilizadores a controlar receitas, despesas e hábitos financeiros de forma simples, visual e inteligente.

A aplicação permite o registo de movimentos financeiros, análise de gastos e visualização de dashboards interativos, além de integrar um assistente virtual baseado em inteligência artificial para apoio na tomada de decisões financeiras.

O sistema foi desenvolvido como uma **Web App responsiva com Flask e Bootstrap**, utilizando **SQLite como base de dados no MVP**.

---

## Objetivo do Projeto

O objetivo do LombongoCare é permitir que qualquer utilizador:

- Registe receitas e despesas
- Organize despesas por categoria
- Visualize o seu saldo financeiro em tempo real
- Acompanhe a evolução dos seus gastos
- Receba recomendações financeiras através de IA
- Desenvolva hábitos de poupança e controlo financeiro

---

## Funcionalidades

### Autenticação

- Registo de utilizador
- Login seguro
- Hash de password
- Sessão com Flask-Login ou JWT

---

### Gestão Financeira

- Adicionar receitas
- Adicionar despesas
- Categorizar despesas
- Definir periodicidade (diária, semanal, mensal)

---

### Dashboard Financeiro

- Total de receitas
- Total de despesas
- Saldo atual
- Evolução mensal
- Percentual de gastos por categoria

---

### Gráficos

- Gastos por categoria (Pie Chart)
- Evolução de receitas vs despesas (Line Chart)
- Fluxo financeiro mensal (Bar Chart)

---

### Assistente Virtual (IA)

Integração com API de inteligência artificial para:

- Analisar padrões de consumo
- Sugerir cortes de gastos
- Criar planos de poupança
- Alertar sobre gastos excessivos
- Gerar recomendações personalizadas
